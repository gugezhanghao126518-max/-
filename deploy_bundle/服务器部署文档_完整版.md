# 服务器部署文档（完整版）

## 1. 项目目标
- 在服务器上运行网页版本，不需要本地图形界面。
- 浏览器打开后可完成：Excel/CSV 预览、文章抓取、日志查看。

## 2. 环境要求
- Linux 服务器（Ubuntu/CentOS）
- Python 3.9+
- 对外网络可访问目标文章站点
- 开放 TCP 7860 端口

## 3. 安装与启动
```bash
cd /你的项目目录
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python web_ui_server.py
```

## 4. 访问地址
- 本机调试：`http://127.0.0.1:7860`
- 远程访问：`http://服务器公网IP:7860`

## 5. 云安全组/防火墙
- 云平台安全组：放行 TCP 7860
- UFW 示例：
```bash
sudo ufw allow 7860/tcp
sudo ufw reload
```

## 6. 开机自启（systemd）
1) 将 `systemd_service_example.service` 拷贝到：
`/etc/systemd/system/article-webui.service`

2) 执行：
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now article-webui
sudo systemctl status article-webui
```

3) 查看日志：
```bash
sudo journalctl -u article-webui -f
```

## 7. 域名反向代理（Nginx）
- 参考 `nginx_reverse_proxy_example.conf`
- 配置后可用域名访问，并可挂 HTTPS。

## 8. 运维完成后要给业务同学的信息
- 可访问地址（IP或域名）
- 服务状态截图（`systemctl status`）
- 最近 20 行日志（`journalctl -n 20`）

## 9. 常见问题
- 打不开页面：端口未放行/进程未启动。
- 抓取失败：目标站反爬或网络超时。
- 上传失败：文件不是 csv/xlsx/xls。
